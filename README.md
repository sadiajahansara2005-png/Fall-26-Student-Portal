# NEUB Fall 2026 - Student Portal 🎓

A modern, interactive, and fully responsive student portal designed for the **Fall 2026** batch of Northeast University Bangladesh (NEUB). Built with a premium Glassmorphism UI.

## ✨ Features

- **📊 Dashboard Overview:** Quick glance at total active students, section, and semester details.
- **👥 Student Directory:** A complete list of all students with Search functionality. Includes a special visual **CR Badge** for Class Representatives.
- **📅 Interactive Class Routine:** Clickable daily schedule cards that open a beautiful glass-effect modal popup showing class time, faculty, and room numbers.
- **🌓 Dark/Light Mode:** Seamlessly switch between light mode and a deep space dark mode theme.
- **📥 Export Options:** One-click export student list to Excel (.csv) or Print directly from the browser.
- **📱 Fully Responsive:** Adaptive design with a mobile-friendly hamburger menu and swipeable tables.

## 🚀 How to Run Locally

This project is purely frontend-based (HTML, CSS, Vanilla JS) and requires no backend server to run.

1. Clone or download this repository.
2. Ensure you have the folder named `Student Portal`.
3. Make sure your logo is named `logo.jpeg` and is placed inside the folder.
4. Simply double-click on `index.html` to open it in any modern web browser (Chrome, Edge, Safari, Firefox).

## 🛠️ Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Glassmorphism (backdrop-filter), and Keyframe Animations.
- **Vanilla JavaScript:** DOM manipulation, modal toggling, search filtering, and CSV export logic.
- **FontAwesome:** For intuitive UI icons.
